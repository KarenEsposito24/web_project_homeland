# De patria a patria

## Descripción del proyecto

Este proyecto es una página web artística y cultural creada para la Galería de Arte TripleTen. Su objetivo es presentar historias, fotografías y descripciones de distintas ciudades del mundo, representando la diversidad cultural de las personas que forman parte de la comunidad TripleTen.

La página invita a los usuarios a conocer los lugares de origen de sus colegas en línea, creando una experiencia visual y narrativa que conecta culturas, identidades y territorios a través del arte y la tecnología.

## Funcionalidad

- Presentación de historias y paisajes de diferentes países
- Visualización de galerías de imágenes organizadas por ciudad
- Información detallada de cada lugar y sus artistas
- Diseño visual limpio y organizado
- Navegación clara entre secciones

## Tecnologías utilizadas

- **HTML5**: Estructura semántica del contenido
- **CSS3**: Estilos y diseño visual
- **Grid Layout**: Organización de las galerías de imágenes
- **Flexbox**: Alineación y distribución de elementos
- **BEM**: Metodología para la organización del código CSS
- **Git**: Control de versiones del proyecto

## Planes de mejora del proyecto

- Implementar JavaScript para mejorar la interactividad
- Añadir animaciones suaves para transiciones entre secciones
- Optimizar imágenes para mejorar el rendimiento
